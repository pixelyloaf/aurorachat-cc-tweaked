# aurorachat-cc-tweaked

i do not recommend using this on multiplayer servers or atleast using the floppy save feature

installing should be running this command in cc tweaked
```bash
wget https://raw.githubusercontent.com/pixelyloaf/aurorachat-cc-tweaked/main/auc.lua auc.lua
```

this client features
- messaging
- history
- room switching
- dms
- auto login through floppy disks
- muting people (saved onto floppy disks)
- speaker support
